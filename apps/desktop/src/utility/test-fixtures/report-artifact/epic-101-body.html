Reports with today's date and one price

✓ Done · checked on a local copy · ○ not yet in production · 2 steps wait on Artem, who deploys B2Buster

In short

B2Buster writes AI research reports for business clients: which companies to sell to, at what price, and on what sources. On 22 October Oleksandr found reports that read as if written on an old date, quoted stale sources, gave one offer two different prices, and once listed B2Buster as its own target client.

This work fixes those mistakes, adds a last check that catches sections contradicting each other, and adds an admin page that shows what each report was built from.

What changed

ProblemFixWhat happens now
Stale dates. The AI had no idea of today's date, so reports could read as written in the past. Every AI call gets one sentence with the date: day only, fixed for the whole run.

Every call says today's date; a recovered report keeps the date it was created. B2B_PROMPT_DATE_ENABLED turns this off.

✓ backend tests, including a recovered report
Old sources ranked like new ones. Library results with a known date sort newest first among sources trusted equally. Nothing is removed and scores don't change.

Sources show their real publish day. Fresh items come first; undated items keep their place.

✓ backend tests
One offer, two prices in different sections. One shared price table that every section uses; the checker now also reads prices inside table cells.

A price that disagrees across sections is labelled where it appears and listed under "Pricing scenarios".

saved and made-up test reports only · ○ not yet on a new real report
B2Buster listed as its own target account (seen in a real report). The client's own company is removed from target lists.

The client no longer appears as its own target in the saved report that showed it.

saved report · ○ not yet on a new real report
No final cross-check. One review pass after delivery looks for sections that contradict each other.

Capped at $0.40 per report; B2B_FINAL_REVIEW=off turns it off. Minis (short reports) are not reviewed.

✓ caught 8 of 11 planted defects, 0 of 6 false alarms ($0.57 test)
No way to see what a report used. A new admin page: Admin → user → report → Report evidence.

It shows counts only: searches, items admitted, items cited, and the split between library, web and client.

Also fixed

  • A client price counts as the client's own only when offer, region, unit and period all match their answers.
  • Where we can't tell what came from the client, the report says "not measured" instead of guessing.
  • A stale background worker can no longer overwrite a delivered section unnoticed: the admin page shows "changed".

Whole suite: 28,084 of 28,085 backend tests, 1,038 of 1,039 database tests and 6,769 frontend tests pass (both misses also fail without this work) · two independent reviews, 15 findings, all closed · automated checks on GitHub (CI) 5 of 5 green.

Still open

  • ○ Not run in production yet. The price and target fixes are proven only on saved and synthetic reports.
